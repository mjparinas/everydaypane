# Tempest weather station

Household only. The **Tempest** widget shows live observations from your WeatherFlow station.

## Setup

1. Station id from the Tempest app or [tempestwx.com](https://tempestwx.com).
2. **Data authorization token** from Tempest › Settings › Data Authorizations.
3. **Settings › Weather stations** — station id and token (token is encrypted on the server).
4. Add a **Tempest** widget to a view.

Observations are cached for about a minute; displays poll every minute.
