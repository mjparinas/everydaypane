# Weather Underground (PWS)

Household only. The **Weather Underground** widget shows the current observation from a personal weather station.

## API key

IBM/Weather Company PWS API key — set `WU_API_KEY` on the server, or save a per-household key under **Settings › Weather stations**.

## Station id

Public station id (e.g. `ICALANG13`) in **Settings › Weather stations** and on the widget if you use one station per dashboard.

Cached five minutes.
